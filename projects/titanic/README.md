# Titanic Survival Analysis

## Overview

This project presents a complete end-to-end Data Analysis workflow using the Titanic dataset. The objective is to explore the factors that influenced passenger survival by following a structured and professional data analysis process.

The project is designed as a portfolio-ready case study that demonstrates industry-standard practices in data cleaning, exploratory data analysis (EDA), feature engineering, and data preparation for machine learning.

---

## Project Objectives

- Understand the business problem and project objectives.
- Assess the overall quality of the dataset.
- Clean and preprocess the data using best practices.
- Perform business-driven exploratory data analysis.
- Generate meaningful insights supported by visualizations.
- Engineer useful features for future modeling.
- Prepare business-ready and model-ready datasets.

---

## Dataset

The dataset contains demographic and travel information for passengers aboard the RMS Titanic.

Each observation represents a single passenger and includes information such as:

- Passenger Class
- Age
- Gender
- Fare
- Family Relationships
- Cabin Information
- Port of Embarkation
- Survival Status

**Target Variable**

- **Survived**
  - 0 → Did Not Survive
  - 1 → Survived
