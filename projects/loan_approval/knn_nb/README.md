# Loan Approval: KNN and Naive Bayes Project

## Overview

Two predictive tasks on the same loan_approval_dataset.csv:

1. Classification: predicts loan_status (Approved/Rejected) using KNN Classifier and
   Gaussian Naive Bayes, with loan_amount included as an input feature.
2. Regression: predicts loan_amount using KNN Regressor only. Naive Bayes is not applicable
   to regression. loan_status is excluded from this task to avoid target leakage.

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the notebook end to end to train all models and export artifacts to models/:
   jupyter notebook notebooks/LoanApproval_KNN_NaiveBayes.ipynb

3. Launch the Streamlit application from the project root:
   streamlit run app/streamlit_app.py

The app has two tabs: Loan Approval Classification (choose KNN or Naive Bayes) and
Loan Amount Regression (KNN only). It will not run until the notebook has been executed
at least once, since the model artifacts in models/ are generated by the notebook.
